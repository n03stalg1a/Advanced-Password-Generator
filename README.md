
# 🚨 n03stalg1a's Password Generator 🚨

Welcome to **n03stalg1a's Password Generator** — the tool you never knew you needed to generate super secure, cryptographically strong passwords. Perfect for those who want to keep their data *extra* safe without compromising on convenience.

## 🛠 Features:
- **Total Security**: Generated passwords are as strong as your coffee (or stronger).
- **Super Customizable**: You can tweak settings for uppercase, lowercase, digits, and special characters. Pick your poison!
- **Say No to Common Patterns**: No more "12345" or "password" nonsense. We’ve got your back.
- **Entropy?**: Of course. We’ll give you feedback on how strong your password really is.

## 🖥 Requirements:
- Python 3.x
- You’ll need `colorama` and `pyfiglet` to run this thing.
  
### Install the goodies:
Just run this to install dependencies:
```bash
pip install colorama pyfiglet
```

## ⚡ Usage:

1. **Clone** or **Download** this repo.
2. Run the script like a pro:
   ```bash
   python nsa_password_generator.py
   ```
3. Watch as it spits out a password, shows you how strong it is, and even saves it in a folder named by the date. Neat, huh?

## 💥 Example Output:

```bash
Generated Password: Hh3F!g4QzP9$wN7YkzG
Password Entropy: 152.79 bits
Password strength is high. Your password is secure.
```
